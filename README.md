# Moist Entropy Weather

Лёгкое Next.js/PWA-приложение, которое показывает текущую погоду и физически осмысленный **Moist Entropy Index** — относительный индекс термодинамического состояния влажной воздушной массы.

## Зачем ещё один показатель

Обычная температура не различает сухие и насыщенные водяным паром воздушные массы. При одинаковых 25 °C запас скрытой теплоты и субъективная духота могут сильно отличаться. Индекс объединяет температуру, давление и количество водяного пара, поэтому дополняет температуру, влажность и стандартное «ощущается как».

Это **не абсолютная энтропия воздуха** и не медицинский heat index. Это относительный энтропийный индекс относительно условного сухого эталона при 0 °C и 1000 hPa:

1. Давление насыщенного пара рассчитывается по формуле Магнуса;
2. из относительной влажности получается mixing ratio `r`;
3. вычисляются потенциальная температура `θ` и упрощённая эквивалентная потенциальная температура `θₑ`;
4. индекс равен `cpd × ln(θₑ / 273.15)` в Дж/(кг сухого воздуха·К).

Границы словесной оценки находятся в `lib/comfortScale.ts` и могут калиброваться независимо от физической модели.

## Возможности

- точная геолокация с явным уведомлением о локальном использовании координат;
- поиск города при отказе от геолокации;
- текущая погода, полный набор термодинамических величин и наглядная шкала;
- fallback на давление на уровне моря с предупреждением;
- ручной калькулятор и сравнение сухого/влажного воздуха;
- автообновляемый service worker, offline-экран, manifest и адаптивная светлая/тёмная тема;
- чистые типизированные расчёты с unit-тестами, без backend и API-ключа.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Для production-проверки используйте `npm run build && npm start`, тесты запускаются командой `npm test`.

## Деплой на Vercel

1. Импортируйте Git-репозиторий в Vercel.
2. Vercel автоматически распознает Next.js; переменные окружения не нужны.
3. Нажмите **Deploy**. Геолокация работает на HTTPS-домене Vercel.

Проект также можно развернуть на Netlify с официальным Next.js runtime.

## API и приватность

- [Open-Meteo Forecast API](https://open-meteo.com/en/docs) — текущие метеоданные;
- [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api) — ручной поиск города.

API не требует ключа. Координаты передаются браузером непосредственно Open-Meteo только для получения прогноза; приложение не имеет backend, не сохраняет и не анализирует местоположение.

## Ограничения модели

- это приближённая термодинамическая оценка с упрощённой формулой `θₑ`;
- точность зависит от погодной модели, координат и качества исходных данных;
- микроклимат улицы, тень, ветер у конкретного здания и прямое солнце не учитываются;
- при отсутствии surface pressure используется менее точное pressure MSL;
- индекс не является медицинским показателем и не заменяет официальные предупреждения о жаре и опасной погоде.
